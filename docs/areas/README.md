# Area docs

One file per row of the Product areas table in [../../MAP.md](../../MAP.md), same template (Purpose, How it works, Files, Data read and written, Logic IDs used, Quality checks, Metrics, Security notes, Known limits, Open items, History, Last verified). They point at the handbook for rules; they do not copy it. When a task changes an area's main files it also updates that area doc's History.
