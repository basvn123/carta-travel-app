# Carta Intelligence API 1.0.0 (OpenAPI)

Generated by `python -I scripts/docs/build_reference.py` from `services/intelligence/openapi.json` (written by `python -m intelligence.openapi_dump` in `services/intelligence/`). Do not edit by hand. ROADMAP F5, T1154; README `services/intelligence/README.md`.

Carta Intelligence: the travel taxonomy, tagging, place linking, similar items and the taste profile as one internal API (ROADMAP F5). Read only: nothing is stored, and no request or response body is logged. Runs on the build box for the pipeline's batch jobs; not exposed to travellers. Auth: an API key in `X-API-Key` (or `Authorization: Bearer`). Rate limit: a token bucket per key; 429 with `Retry-After` when empty.

OpenAPI 3.1.0. Security schemes: `APIKeyHeader` (apiKey X-API-Key), `HTTPBearer` (http bearer).

## Operations

| Method | Path | Summary | Request | Responses | Key |
|---|---|---|---|---|---|
| GET | `/healthz` | Liveness, no key | none | 200 | no |
| POST | `/link` | Link messy place mentions to catalogue places (F4 linker) | LinkRequest | 200, 401, 422, 429, 503 | yes |
| GET | `/metrics` | Prometheus metrics | none | 200, 401, 429 | yes |
| POST | `/profile` | The taste profile from a traveller's saves, trips and filters (F3) | ProfileRequest | 200, 401, 422, 429, 503 | yes |
| POST | `/similar` | Items like an item, or carrying given tags (TF-IDF cosine over F1 tags) | SimilarRequest | 200, 401, 422, 429 | yes |
| POST | `/tag` | Tag catalogue items or free text on the travel taxonomy (F1 tagger) | TagRequest | 200, 401, 422, 429 | yes |
| GET | `/taxonomy` | The travel taxonomy | facet (query) | 200, 401, 422, 429 | yes |
| GET | `/taxonomy/{node_id}` | One taxonomy node | node_id (path) | 200, 401, 422, 429 | yes |
