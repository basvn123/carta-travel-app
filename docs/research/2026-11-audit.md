# Carta audit, November 2026

Nov 4, 2026, @Bas. A full read-only audit of Carta as it is today: the live site, the shipped data, the pipeline and operations, the code, the open-items register, and everything a full-time consumer product needs beyond the features. Every pain point has evidence, an impact, a fix and the roadmap item that carries the fix ([ROADMAP.md](../ROADMAP.md)).

## How this audit was done

| Lane | What was checked | Evidence |
|---|---|---|
| Live app | carta-europetravel.com walked at 1440 px and 375 px: Home, Explore, Trails, a trail page, Hallstatt, Ask Carta, Plan | Browser session, console, network |
| Data | Every shipped wire file counted field by field, split by rating band and country | Scripts over `continent-app/public/` and `app_data/` |
| Pipeline and ops | Task state, logs, scheduled tasks, scrapers, flight sweep, deploys, 657 "What broke" entries in 151 reports | Logs, Task Scheduler, reports, status JSON |
| Code | Lint, fast build, bundle, size and churn, dead code, error handling, `npm audit`, headers, accessibility | `npm run lint`, fast build, `npm audit`, `npm test` (1,229 of 1,229 pass) |
| Register | All 1,592 rows in `docs/owner/` classified by area, theme, owner, age, staleness | Classification CSV in the session scratchpad |
| Product completeness | Onboarding, accounts, retention, mobile, money, support, analytics, growth, content ops, languages, business ops | Code and docs |

## Severity scale

| Level | Meaning |
|---|---|
| **S1 Critical** | Broken in production, a security exposure, or a legal block on running the business |
| **S2 High** | A traveller sees wrong, missing or slow content on a core flow |
| **S3 Medium** | Hurts quality, trust or speed of work, but has a workaround |
| **S4 Low** | Polish and hygiene |

## 3. What is healthy

- Tests: 1,229 of 1,229 app tests pass; 321 Python tests collected.
- Coordinates, climate, food prices, rating scores (99.7%), hero images (99.3%) and outdoor photos (100%) are complete.
- Flights: 10,094 routes; from Brussels 78 destinations, fares a median 8.4 days old.
- Stays observations are fresh (5 to 12 days) where they exist.
- No secrets in the code; strict CSP with HSTS preload; every fetch checks errors; every image has alt text.
- The place page, Explore and the cost card read as a finished, coherent product on the live site.

## 4. Where the fixes went

Every P-ID above is carried by a roadmap item. New items added for this audit: the **Fix now** block (N1 to N8), data items D7 to D13, E6, G12 and G13, H9 to H14, and a new **Track I: product and business** (I1 to I13). Launch moved to Track J.
