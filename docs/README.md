## Keeping it true

A task that changes how a feature works updates its handbook section and its area doc's History in the same commit (CLAUDE.md, step 6). A number in a doc names the config key or constant behind it. Where something was not checked, the doc says "not verified". Drift checks arrive with ROADMAP B7.
