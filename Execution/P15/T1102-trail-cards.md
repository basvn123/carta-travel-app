# T1102: Trail cards and trail links (G13)

## Date

2026-11-06

## What changed

The top-band "Top-rated walks" rail tile showed only grade and length. It now carries length, walking time and climb in one line ("16.4 km, 7 h 50 min, +985 m"), the same three the list card already shows as badges. An open walk now has its own address: `#trail=ID&tc=CC` is written on the history entry the layer pushed, so it can be shared, bookmarked and reached with Back, and closing it (control or Back) clears it. Cold loads of the address already opened the walk; they still do. From a place page, the "Around here" rows are now real links to each feature's own address (before: buttons with no URL); the trail page already linked back to its town ("Stay nearby"). T1092 names and per-day grades and the T1093 credit are used unchanged.
