# Carta map

Where each part of Carta lives. Find the area, open the files named, stop.

- **How a feature works** (rules, formulas, thresholds): its part of [docs/HANDBOOK.md](docs/HANDBOOK.md), named in the Handbook column. Grep the handbook for the feature; never read it whole.
- **One area on a page** (files, tests, limits, open rows): [docs/areas/](docs/areas/README.md), one file per row below. **Everything else in docs/**: [docs/README.md](docs/README.md).
- **Where a wire field comes from** (writer, task, app reader): [docs/architecture/lineage.md](docs/architecture/lineage.md), generated by `scripts/docs/build_lineage.py`; each request path drawn in [docs/architecture/request-paths.md](docs/architecture/request-paths.md). **Every config key and its readers**: [docs/reference/config.md](docs/reference/config.md), generated by `scripts/docs/config_reference.py`.
- **What is planned**: [ROADMAP.md](ROADMAP.md). **What hurts today**: [docs/AUDIT-2026-11.md](docs/AUDIT-2026-11.md).
- App paths start with `app/`, meaning `continent-app/` (tracked in this repo).
- "Latest" are the newest task reports on the area: grep `Execution/P15/` and `Execution/P*/_DIGEST.md` for the ID.
- The old docs were archived on 2026-11-04 (T1050) to `archive/docs-2026-11/`. Do not read them to find your way; the handbook and the code win.
- Checked against the code on 2026-11-04 (T1051). `scripts/docs/check_entry_points.py` fails if a path below does not exist. A task that moves an area's main files updates its row.

## Pipeline

`python run_pipeline.py <task>` from the repo root; the `TASKS` table is `pipeline/tasks/<domain>.py`, joined in `DOMAINS` order (`pipeline/tasks/__init__.py`, T1207). The ones touched most:

| Task | Does |
|---|---|
| `fame` | fame, designations, beauty, place and traveller rating |
| `poi_significance` | POI signals, dedupe, re-tier, rating |
| `trips` | ready-made 2 to 14 day trips into public/trips |
| `dossier` | the per-place contract for the page and the PDF |
| `stays` | Booking and Hostelworld scrape into the live stays wire |
| `food` | food and drink prices per place |
| `airports` | airports in reach per place, transfer per mode |
| `trails_rate` | the 0 to 10 trail rating (end of the trails_* chain) |
| `rating_v5_profile` | nature items on the place ladder, place taste profile |
| `ask_index` | Ask Carta passages, vectors and BM25 |

Others: `beaches`, `lakes`, `mountains`, `joins`, `regions`, `crowding`, `climate_daily`, `cycling_*`, `image_audit`, `photo_sources`, `trailslab_worker`.
