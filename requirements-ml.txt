# Machine-learning dependencies for two pipeline layers, in TWO halves that
# cannot share one environment (T1161, T1211): model2vec 0.10.0 needs
# huggingface-hub 1.0 or newer, sentence-transformers 3.3.1 (through
# transformers 4.x) needs it below 1.0, so one pip call over this whole file
# fails with ResolutionImpossible. Install each half on its own, as the box does
# (infra/hetzner/cax11/run_pipeline.sh, CARTA_BOX_ML):
#
#   # half 1, the Ask index, into the main environment (no torch):
#   python -m pip install model2vec==0.10.0 -c constraints.txt
#   # half 2, guided search, into its own venv (CPU torch first, as on the box):
#   python -m venv ~/venv-guided
#   ~/venv-guided/bin/python -m pip install -r infra/hetzner/jobs/requirements-torch-cpu.txt
#   ~/venv-guided/bin/python -m pip install sentence-transformers==5.6.0 "huggingface-hub>=0.34,<1.0" -c constraints.txt
#   # then run guided_search with CARTA_GUIDED_PY=~/venv-guided/bin/python
#
# On Windows the venv python is ~/venv-guided/Scripts/python.exe. The box
# reads this file by line: the model2vec line is half 1, every other package
# line is half 2. Keep one package per line.

# constraints.txt pins.
sentence-transformers==5.6.0
