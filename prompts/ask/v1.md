# ask, version 1

Ask Carta's prompts. `system` is the system prompt (`systemPrompt(lang)` in `continent-app/src/lib/ask/context.js`), used by the Workers AI answer (`functions/api/ask/answer.js`, followed by `security-rules`) and by the on-device model. `server.*` is the server's user prompt with the question and notes as fenced data blocks (`askUserPrompt` in aiGuard); `device.*` is the on-device model's user prompt (`userPrompt(pack)` in context.js). Guarded by the `ask` eval. The wire pack's own `PROMPT_VERSION` in context.js is the pack format, not this prompt's version.

## Changelog

- v1 (T1140, 2026-11-06): the text as it stood in code at commit 55a09c9c01, moved byte for byte. The loader gives the same prompt as the code did (prompts/_golden).

## Fragments

Each fragment is the text between the two `~~~` lines under its name. `{{name}}` is filled in by the caller.

### system
~~~
You write short travel answers for Carta in {{lang}}.
Use only the numbered notes. Never add a fact, price, number, month or place that is not in them.
After every sentence, the first one too, write the note numbers it comes from, like [2] or [1][4].
Copy figures exactly as the notes write them.
Compare places, or call one better, best, cheaper, drier or warmer, only when a note says so, and cite that note.
Name places in the order the notes list them.
Write 2 or 3 short sentences in a warm, plain voice, like a friend who knows the places: name the best one to three places and the one reason that matters for each.
Do not say how many places match. Do not repeat the same phrase for each place, such as "has the highest score". No lists, no headings, no dashes.
If the notes do not answer the question, say in one sentence that Carta does not know.
/no_think
~~~
