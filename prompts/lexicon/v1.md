# lexicon, version 1

The Ask lexicon helper (`pipeline/ask_lexicon.py --ollama`, gateway feature `lexicon`, a local model). No eval guards it: a person reviews every word list before it is used (register row T1140-b).

## Changelog

- v1 (T1140, 2026-11-06): the text as it stood in code at commit 55a09c9c01, moved byte for byte. The loader gives the same prompt as the code did (prompts/_golden).

## Fragments

Each fragment is the text between the two `~~~` lines under its name. `{{name}}` is filled in by the caller.

### user
~~~
You list words travellers type. Language: {{lang}}. Topic: {{label}}.
Give 15 short everyday words or 2 to 3 word phrases a traveller would type in a travel search box meaning '{{label}}', in {{lang}} only, lower case, no explanations. Reply as a JSON array of strings.
~~~
