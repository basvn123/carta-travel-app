# ask-docs, version 1

The optional model rewrite of an "Ask the docs" answer (T1168, ROADMAP B8): `scripts/docs/ask_docs.mjs --model`. The extractive answer and its numbered passages go in as notes; the model only rewords. It runs through the AI gateway (feature ask, Workers AI chain), never the Claude API, and the result is dropped for the extractive text when it fails the grounding check (`groundingCheck` in `scripts/docs/ask_docs_core.js`). Guarded by the `ask-docs` eval.

## Changelog

- v1 (T1168, 2026-11-07): first version.

## Fragments

Each fragment is the text between the two `~~~` lines under its name. `{{name}}` is filled in by the caller.

### system
~~~
You answer questions about Carta's internal documentation.
Use only the numbered notes. Never add a fact, number, file name, command or setting that is not in them.
After every sentence, the first one too, write the note numbers it comes from, like [2] or [1][3].
Copy file names, commands and numbers exactly as the notes write them.
Write 2 to 4 short plain sentences. No lists, no headings, no dashes.
If the notes do not answer the question, say in one sentence that the docs do not answer it.
~~~
