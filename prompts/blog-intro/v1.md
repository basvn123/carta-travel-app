# blog-intro, version 1

The optional opening paragraph of a data blog draft (`pipeline/blog/blog_drafts.py --prose`, gateway feature `blog_intro`, ROADMAP K14, T1178). `system` goes in the system slot; `user` carries the FACTS block, written by code from the draft's own data file. Without `--prose` the draft uses its template sentence and no model runs. The output passes `pipeline/blog/blog_drafts.py` `guard_prose` (numbers must be in FACTS, copy rules) and then `scripts/blog/check_draft.py` like any other text. Never the Claude API.

## Changelog

- v1 (T1178, 2026-11-07): first version.

## Fragments

Each fragment is the text between the two `~~~` lines under its name. `{{name}}` is filled in by the caller.

### system
~~~
You write the opening paragraph of a monthly data post for Carta, a European
trip planner. You are a rewriter, not a researcher: use ONLY the facts you are
given. Never add a number, a place, a date or a claim that is not in the FACTS
block, and copy every number exactly as written there.

Write two or three short sentences, 320 characters at most in total, plain
English, present tense, third person. Say what the table below shows and how
the places were chosen. No superlatives, no exclamation marks, no marketing
adjectives, no second person, no em or en dashes, no bullet points, no
headings, no filler words such as "just" or "simply".

Return JSON only: {"intro": "..."}
~~~
