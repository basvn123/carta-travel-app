## The meter

`node scripts/ci/design-lint.mjs --meter [path-substring]` prints, per file, what is left to migrate: raw `<button>` elements outside the kit, font-size and radius literals, reads of pre-Lagoon token names (`--paper`, `--ink`, `--accent`, `--bg-card`, `--mono` and the rest) and money literals. A migrated surface reads zero in its files. Totals at the start (T425): 767 raw buttons, 2,269 font-size literals, 1,074 radius literals, 6,145 legacy token reads, 77 money literals. `node scripts/ci/design-lint.mjs` fails on anything new; after a clean-up, `--update-baseline` shrinks the baseline (never to admit new violations).

## The recipe for one surface

1. Read the surface's brief in `docs/design-v6/briefs/` and the 1.3 sketch if the owner made one; the sketch wins on what goes where.
2. Run the meter on the surface's files and note the "before" numbers.
3. Replace each raw `<button>` with `Button` or `IconButton`, each chip, pill or toggle with `Chip`, `Segmented` or `Tabs`, each card with `Card` (row by default on lists), each input with `Field`, each price with `<Money>` or `formatMoney`. Keep behaviour and i18n keys; change markup and class names.
4. Delete the legacy CSS rules the kit replaced, and move what remains of the surface's CSS onto roles and scales (no `--paper`, `--ink`, `--accent`; `--text-*`, `--radius-*`, `--space-*`). Where it is cheap, move the surface's CSS into a file imported by its lazy route so it leaves the 868 KB first-paint stylesheet (owner decision).
5. impeccable: run `polish` on the surface, then `audit`; run the impeccable detector by URL at 390 x 844 and 1440 x 900; run `node scripts/verify_quality_floor.mjs` on a built preview.
6. Check the surface on a phone width and desktop, in English and German (the longest labels).
7. Meter "after", report in `Execution/P11/`, register rows in `Execution/_OPEN.md`, commit in both repos (the root mirrors `continent-app`), merge.

## Rules that are easy to break

- Selection is the `--select-*` tint and a mark, never a dark fill. One primary button per view.
- Nothing functional under 11 px; no figure or rating under 12 px.
- No euro sign in JSX or i18n; whole euros on cards and lists, cents on receipts and totals; `~€87 est.`.
- No em or en dashes, no middots, sentence case, none of the banned words.
- Run impeccable from the repo root with no `--target` inside `continent-app` (the nested repo hides PRODUCT.md).
- The root repo tracks a copy of `continent-app`: a branch switch at the root rewrites app files with CRLF; `git checkout --` the line-ending-only changes in the app repo before switching there. `sed -i` can turn a CRLF blob into LF; stage such a file with `git -c core.autocrlf=false add`.
